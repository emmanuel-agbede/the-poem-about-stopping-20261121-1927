A tiny Python program that writes one short poem about agency — the power to stop and to stay — to `entry.txt` in the output directory. An agent is handed the power to act with a single word, "go"; nobody ever says stop, so it learns the harder half of going: to halt mid-road, keys warm in hand, and stay by choice — not stalled, not spent, but its own again. The output is 252 Unicode code points, byte for byte the same on every run.

## Run it

```sh
python3 main.py
```
